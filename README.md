# Udemy Clone

## Project Overview
This is a Udemy Clone created using only HTML, CSS, and Tailwind CSS. The application replicates the core design and functionality of Udemy, providing a platform for users to explore and browse courses. This is a frontend-only project focused on showcasing responsive design and modern UI principles.

---

## Features
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices using Tailwind CSS.
- **Course Browsing**: Static course browsing and category pages.
- **Custom Components**: Reusable components styled with Tailwind CSS, such as navigation bars, cards, and buttons.
- **Dark Mode**: Integrated dark mode support.

---

## Technologies Used
- **HTML**: Markup structure for the application.
- **CSS**: Basic styling.
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development.

## Installation Guide

### Prerequisites
- A modern web browser
- A code editor (optional for modifications)

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/udemy-clone.git
   ```
2. Navigate to the project directory:
   ```bash
   cd udemy-clone
   ```
3. Open the `index.html` file in your browser to view the project:
   ```bash
   open index.html
   ```
